# 桌面客户端

Electron / React 客户端使用同一 Go 会话服务。个人任务以对话为中心，保留青夜颜色、固定输入区、可展开的工具过程和独立工作区入口。

## 连接与使用

「设置 → 运行主机」提供「此 Mac」和「迷你主机」配置。选择此 Mac 时，应用启动自己的 loopback 服务与随机 `EA_SERVER_API_KEY`。选择远程主机时填写 `http(s)://主机:端口` 和服务令牌，空令牌保留已保存的值。

「设置 → 模型连接」支持为此 Mac 配置 OpenAI 兼容服务或 Anthropic 的服务地址、默认模型与 API Key，也可以沿用 EasyAgent 的命令行配置。模型密钥通过 Electron `safeStorage` 加密，不回传渲染器；留空保留同一 Provider 的现有密钥，更换 Provider 需填写新密钥。应用配置只重启桌面管理的核心，不修改已运行的 CLI / 8080 服务；存在执行中的任务时拒绝重启。会话历史保留，重启后重新打开的会话和新会话使用更新后的模型配置。

「检测连接」请求服务的模型目录，不生成模型回复。无法发现目录时只展示已配置的模型并说明来源，不生成固定兜底选项。远程模型需在对应服务主机配置，桌面本地配置不影响远程主机。

桌面托管的本地核心使用应用用户目录下独立的 `core-data`，不继承 `EA_DATA_DIR`，避免与已运行的 CLI / Web 核心共用会话及任务凭据。若希望查看已有 8080 服务的历史，应添加连接到该服务的配置；连接远程主机同样共享该主机的历史。

正式桌面应用通过主进程代理 HTTP / WebSocket；远程令牌使用 Electron `safeStorage` 保存，不传给渲染器。不具备安全存储时拒绝保存秘密。连接状态、认证失败、启动错误与重试入口直接显示在界面中。切换主机不会取消旧主机上的任务。

- 输入 `/` 查看共享命令目录，方向键选择，Tab / Enter 补全，Escape 关闭。`/workflow <任务>` 进入已有动态工作流引擎。
- 命令结果随当前会话保留，切换会话再返回仍可查看；关闭结果或重新连接后清除。
- Enter 发送，Shift Enter 换行；服务确认接受前保留草稿。发送结果不确定时重试同一请求标识，避免重复任务。
- 首段输出立即显示，后续增量按渲染帧合并；无逐字播放延迟。工具分组折叠，参数与结果可展开、复制；错误单独说明。
- 向上阅读时保持位置，「回到最新」恢复跟随。长历史使用虚拟列表；模型选择支持搜索。
- 会话工具栏的更多菜单提供完整会话复制与显示密度。顶部按钮直接切换会话列表、底部终端和工作台；设置保留侧栏底部入口，收起侧栏时在顶部提供设置按钮。工作台按可用空间调整，窄窗口使用可关闭浮层；文件区先显示目录，打开文件后显示预览，可切回目录，避免空预览占用聊天空间。
- 再次点击已选中的工作台功能会收起整个右侧栏，未选中功能时不占用对话空间。顶部工作台按钮可重新打开，默认进入文件区。
- 文件浏览、搜索和编辑使用所选会话的项目路径，切换项目会关闭原项目的文件标签。无法读取目录时显示重试入口；文件接口仍要求认证，并限制路径遍历与符号链接逃逸。
- 需要批准的工具在输入区附近显示「允许本次」和「拒绝」。断线后恢复同一任务及待审批操作。
- `/mcp` 或设置中的「MCP 工具」管理当前服务主机的能力，详见 [MCP](MCP.md)。

任务归服务端会话所有。关闭窗口或断网仅停止订阅，不自动取消远程任务；停止按钮针对当前 run。服务进程重启后任务标为中断，旧请求不会自动再执行。已有输出与副作用应先检查，再发起新的任务。该恢复机制不能保证硬断电下的外部副作用恰好执行一次。

## 交互式终端

底部终端位于输入框下方，启动当前服务主机的交互式登录 shell，初始目录为所选会话的项目路径。支持直接输入、Tab 补全、命令历史、Ctrl+C、ANSI 输出与窗口尺寸同步。终端中的命令由用户手动执行，不发送给模型；Agent 的工具执行记录仍在对话中查看。

收起面板保留 shell；切换会话、切换主机、关闭窗口会关闭该终端及前台命令。远程 Agent 任务不受终端关闭影响。当前支持 macOS 和 Linux 服务主机，Windows 核心会明确提示不支持。

桌面托管的本地核心自动启用终端。其他服务需显式设置 `EA_ENABLE_TERMINAL=1` 并配置 API 认证；无认证或未启用时拒绝 `/terminal` WebSocket，仍检查同源策略。终端以服务用户权限运行，不提供文件工具的工作区沙箱。连接老核心时会提示更新，不回退到本机执行远程命令。

## 设置与飞书接入

设置页使用独立的分组导航，分为常规、外观、模型连接、运行主机、MCP 工具与飞书机器人。普通齿轮入口每次打开常规页；页面内分类切换和模型、MCP 等快捷入口进入指定分类，侧栏底部的飞书入口直接进入机器人配置。关闭设置时保持原分类，打开与关闭均不改变原会话、草稿和布局；设置显示时隐藏对话列表与工作台，返回后恢复。

飞书页读取当前所连接主机的 `/settings/feishu` API，提供应用凭据保存、桥接重启、服务与自启动状态，以及一次性私聊配对指令。已有 App ID 固定；App Secret 留空保留现有值，保存后清空输入，已保存的密钥不会回显。配对指令只在主动查看时获取，配对成功、离开页面或切换主机后清除；过期指令不能复制。

本页遵循服务端现有管理边界：服务需配置 `EA_FEISHU_ENV_FILE`、`FEISHU_OWNER_STATE_FILE`、API 认证和 Linux systemd 用户桥接。桌面管理的 Mac 核心目前没有托管飞书桥接；连接已启用管理的服务主机后才能编辑。状态中的“进程运行中”只代表系统服务状态，不能证明飞书 WebSocket 已连通。当前不提供扫码创建应用、多机器人或工作区授权开关。

## 开发预览

需 Node.js 22+、Go 和已配置的模型。只预览界面：

```bash
cd desktop
npm ci --ignore-scripts
npm run dev
```

浏览器预览在设置中连接自己的 Go 服务；跨域时需设置 `EA_ALLOWED_ORIGINS`。预览模式不具备 Electron 安全存储、进程管理或系统 OAuth 回调能力，不应作为正式远程入口。

完整 Electron 开发使用 `npm run electron:dev`，需先构建 `../bin/easyagent` 和动态工作流 bundle（见 [工作流](DYNAMIC_WORKFLOW.md)）。首次安装依赖若跳过 scripts，应运行 `node node_modules/electron/install.js` 安装 Electron 运行时。

## macOS 打包

```bash
# 在仓库根目录执行，按机器架构选择
scripts/build-desktop.sh arm64
# 或 scripts/build-desktop.sh x64
```

脚本使用独立 `desktop/.bundle` 构建 Go 核心、工作流 bundle 与许可证，下载并核验官方便携 Node.js，随后检查 TypeScript、测试并打包。不会替换已有 CLI 或 8080 服务。输出在 `desktop/release.noindex/版本/架构`；包版本来自 `desktop/package.json`，本地打包不自动发布 GitHub Release。

macOS 测试包与安装包的临时挂载放在 `.noindex` 目录，并在检查结束后撤销应用及 Helper 注册，避免旧包反复出现在应用搜索中。原生 GUI 验收或 `electron:dev` 结束后先退出进程，再执行 `python3 scripts/unregister-desktop-apps.py <测试应用路径>`；开发运行时路径为 `desktop/node_modules/electron/dist/Electron.app`。日常安装仅保留 `/Applications/EasyAgent.app` 一份，不把多个测试构建作为启动入口。清理旧副本时保留用户数据及正在运行的应用。

发布构建使用 `scripts/build-desktop.sh arm64 v0.3.1`（或 `x64`），只接受版本匹配的附注 tag、已合入 main 的干净源码；完成后只读挂载 DMG，验证包内核心、运行时、许可证与来源提交。桌面更新提示选择正式版；`v0.3.0` 包含两种 Mac 架构的安装包，历史 RC 仍需手动下载。

更新检查优先查询 GitHub Releases API；遇到匿名 API 限流或网络失败时，使用 GitHub 正式发布的 `release.json` 作为备用源，验证版本、提交及资产摘要格式，再选择本机架构的 DMG。并发检查合并，成功结果缓存一分钟，限流期间遵循服务端重试时间。两条路径都不可用时显示友好提示和“查看发布页”入口，不把查询失败当成已是最新版本。此机制只提示并打开下载地址，不自动安装或验证本地 DMG 下载内容；旧 RC 的内置检查代码须手动升级一次才能获得修复。

当前打包面向 macOS，使用完整的 ad hoc 测试签名并在安装包内校验，未配置 Developer ID 签名与公证。桌面更新提示只匹配架构与桌面 DMG 资产，不把 Go CLI 的 Release 当成桌面安装包。当前正式版本仍使用 ad hoc 签名；Developer ID 签名与 Apple 公证尚未完成，安装说明须保留这一限制。


## 输入、队列与结果

输入区可选择/拖入附件、粘贴截图，输入 `@` 搜索当前项目文件，也可从文件树拖入引用。图片原生传给支持图片的模型；文件工具和路径均属于当前连接的主机。附件单文件不超过 4 MiB，一条消息的图片总计不超过 8 MiB。上传文件保存在项目 `.easyagent/attachments`，上传后移除引用不会删除文件。

任务运行时发送下一条消息会加入服务端队列。队列支持编辑、删除、暂停、恢复；“立即发送”停止当前任务并优先运行选中消息，其余排队消息保留。客户端断线不取消任务；核心重启后队列暂停，待用户恢复，避免自动重放有副作用的指令。

侧栏支持置顶、重命名、归档和恢复；`⌘/Ctrl+F` 查找当前对话正文及工具结果。完成任务后“本轮文件”可打开、导出；PDF 可内嵌预览，Office 文件导出后用系统应用打开。导出和 PDF 上限为 32 MiB。

审阅页按任务选择快照，只对有明确文件工具记录且未发生后续修改的文件开放逐文件撤回。撤回恢复任务开始前内容，保持 Git 暂存区；Bash/MCP 改动来源未确认时不开放撤回。快照最多 2000 个文件、32 MiB 总量、单文件 4 MiB；达到上限会提示并关闭不安全撤回。快照在服务数据目录，附件在项目目录，不自动过期，请纳入备份与清理策略。

“技能与工作流”显示当前会话实际加载的能力；项目技能优先于同名个人技能，支持 `.agents/skills` 的网关同步符号链接，兼容 `.claude/skills`。修改技能后新建会话生效。MCP 默认使用结构化连接表单，高级 JSON 保留其他字段。文件标签与文本预览位置按连接、项目恢复。
