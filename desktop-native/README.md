# EasyAgent Go 原生试用版

MyGo v0.5.5 的原生界面，直接复用现有 EasyAgent Go 核心的 REST/WebSocket 协议。UI 不使用 React、HTML、JavaScript 或 WebView；电脑控制继续使用原有系统助手并随包提供。

这是独立试用入口，Bundle ID 为 `com.hwj.easyagent.native-preview`，不会替换 `/Applications/EasyAgent.app`。

```sh
cd desktop-native
go run ./tools/build
# 使用已准备的资源开发：
EASYAGENT_NATIVE_CORE="$PWD/resources/darwin-arm64/easyagent" go run .
```

构建生成 `build.noindex/darwin-arm64/EasyAgent Native Preview.app` 和安装镜像。构建核心取当前工作树源码；不安装、停止或覆盖已有服务。

## 0.2.3 的项目文件夹选择

本机“选择项目目录”直接打开附属于当前窗口的 macOS 文件夹选择器，取消不改变会话；远程主机使用与原版一致的绝对路径弹窗。选择的目录仅传给新会话，不改写主机默认工作区或已有会话，原会话草稿保留。编程、音乐和知识库模式位于新建会话旁的下拉菜单。

## 0.2.2 的技能市场对齐

技能市场按原版补齐同排搜索与推荐/热门/名称/已安装排序、分类筛选和分页；卡片显示图标、精选、标签、安装量与大小，已安装列表支持行内卸载确认。详情包含使用提示词复制、产出预览图及可用方向键和 Esc 操作的图片预览、示例文件与完整说明；安装状态按技能独立显示并可取消。请求按版本隔离，旧搜索与旧主机响应不会覆盖当前页面。

## 0.2.1 的界面对照与体积

主会话按原版 260px 侧栏、816px 阅读列及与输入面板相同的内容左边界布局；补齐搜索图标、项目折叠、空会话建议、菜单键盘操作、回到最新和收起侧栏后的设置入口。工作台恢复右侧竖向工具栏，终端位于会话底部；工作台宽度与终端高度可拖动或用方向键调整，并保存在设备偏好中。十类设置已在桌面与紧凑窗口检查，操作按钮使用内容宽度，表单、状态文案和技能市场卡片按原版整理。

本机 arm64 构建的完整应用约 154 MB（146.9 MiB），DMG 约 39 MB；此前应用约 179 MB。主要组成是 Node 约 97 MB、Go 核心约 25 MB、原生 UI 约 17 MB，另含工作流脚本、终端库与许可证。构建仅剥离暂存 Node 副本的调试与局部符号，保留导出符号；原始运行时不变。完整动态工作流测试已使用瘦身后的 Node 运行。

## 0.2.4 的界面与交互补齐

MyGo 升级至 v0.5.1，消息改用官方原生 `ui/markdown` 的增量解析、流式补全、任务列表和语法高亮；输入使用 `OnTextKey` 并保留输入法保护。设置语言同步到框架的控件、菜单和编辑器。

文件面板使用懒加载目录树、自动模糊搜索、独立关闭的标签、面包屑及只读/编辑/取消/保存流程；标签、Markdown 预览模式和预览滚动位置按主机与项目保存，恢复只接受项目内路径。PDF 由 macOS CoreGraphics 直接渲染，可翻页、缩放；Mermaid 使用 MIT 的 [go-mermaid](https://github.com/zkrebbekx/go-mermaid) 纯 Go 渲染，可切换源码、复制和缩放，中文标签转换为系统字体轮廓。它是独立兼容实现，尚不支持的 Mermaid 语法会显示源码与原因，不能保证与 Electron 的 Mermaid 引擎逐像素一致。

上下文用量弹窗补齐估算明细、输入检查、图片数据隐藏、压缩记录和手动压缩；计划展示实际 todo 工具状态，审查按运行快照展示差异。工作台主栏恢复原版六项，辅助上下文与工作流仍可从用量弹窗和设置打开。记忆和知识库补齐摘要、分类、标签、搜索和健康检查；能力页展示技能范围、调用方式及工作流结果。终端收起保持 shell，断线可重连，支持 ⌘`；首次添加附件可先创建会话，支持拖入文件，批量上传的失败不会丢弃成功项。

## 0.2.5 的完整页面巡检

对照 Electron 当前源码和实际窗口，补齐会话内搜索（含工具参数与输出）、侧栏行操作和未读标记、工具分组与显示密度、历史文件变更摘要及失败恢复入口。模型菜单支持名称/ID 搜索、方向键与 Enter；提问区区分单选、多选和其他回答，支持预览与跳过。

输入支持 `@` 引用和从文件面板拖入引用，附件与引用随草稿保存；粘贴截图、图片重试和缩放预览已接入。队列操作保留失败草稿并隔离会话；录音显示时长、可取消，转写回到录音开始的会话。飞书桥接修正真实状态字段、配对有效期和托管状态；关闭扫码/MCP 授权页后取消临时流程。文件、审查、知识库和模型菜单的选中样式与缺失图标一并修正。

以临时数据生成 1240×820 与 900×680 的有内容页面，检查十类设置、文件、审查、计划、任务、知识库、记忆、上下文及弹层；交互和真实核心集成测试独立验证保存、流式、审批和隔离边界。第三方账号登录与系统权限仍由使用者完成，不把模拟服务验收当作真实账号授权成功。

## 实际功能

- 本机核心进程的启动、鉴权、重连、退出清理；远程主机保存、切换与重连。
- 会话新建、历史恢复、搜索、重命名、置顶、归档、删除、用户消息编辑分支和回复分支。
- 发送确认后清空草稿；流式文本、思考、工具记录、任务审批、用户问答、停止、断线恢复和失败重试。后台任务完成不会切走当前会话。
- 消息队列、暂停/继续、编辑、立即发送、移除，附件上传（每个 1 字节至 4 MiB），原生录音和后端 ASR 转写。
- 真实模型目录、会话模型切换、本地模型检测、配置保存与重启。后台仍有任务时拒绝重启。
- 十类设置：常规、外观、模型连接、用量统计、技能市场、实验、运行主机、MCP 工具、技能与工作流、飞书机器人。
- MCP 项目信任、配置表单/JSON、连接、工具开关、OAuth 回调、授权和删除；技能市场搜索、详情、安装进度、取消与卸载。
- 文件浏览、搜索、多标签编辑、Markdown/图片预览、保存、导出；文件按主机和工作区隔离，保存前检查外部修改。
- 运行文件差异和受版本校验保护的撤销；原生终端通过服务的鉴权 WebSocket 连接，可查看任务、计划、上下文、记忆、知识库和工作流，并执行对应管理操作。
- 音乐工具结果的原生播放、暂停、进度、音量和跨会话播放。

快捷键：Enter 发送，Shift+Enter 换行，⌘N 新会话，⌘P 工作台，⌘⇧G 审查，⌘, 设置，⌘F 搜索当前会话。命令菜单支持上下选择、Tab/Enter 补全和 Esc 关闭。

## 数据与配置

偏好、主机元数据、模型元数据和草稿保存在此应用自己的 UserData 目录。模型密钥和远程主机令牌保存在 macOS 钥匙串，不写入 JSON。

本机核心使用独立的 `core-data` 和 `EA_HOME=core-home`；MCP、飞书凭据、会话、执行收据与运行覆盖均在此试用目录下。继承模式只读取普通 CLI 的模型/工具默认配置与环境变量。飞书凭据沿用核心格式并使用私有文件权限，手动更新保留已有授权和机器人字段，换 App ID 需要重新绑定。

远程主机上的保存、安装、工具执行、文件写入与删除会实际生效。选择的项目目录和共享个人技能目录也是真实目录。试用前可选择临时项目检查操作，再用于日常工作。

原生界面尚不能宣称与 Electron 全面逐像素一致。Mermaid 使用独立兼容渲染器，PDF 原生预览当前仅在 macOS 实机验证；不同平台的字体、文件选择器及系统授权界面由系统决定。

原生试用包尚未发布独立自动更新通道；“检查更新”读取当前核心版本，不会把 Electron 安装包装进原生应用。桌面/文稿/下载目录访问、飞书登录、MCP OAuth、麦克风及电脑控制需要用户完成对应授权；服务端未配置 ASR 或关闭某项能力时，界面显示实际错误。

## 验证

```sh
go run ./tools/prepare
EASYAGENT_NATIVE_INTEGRATION=1 go test -race -count=1 ./...
go vet ./...
go run github.com/egoist/mygo/cmd/mygo vet
# 可选：系统钥匙串合成凭据往返（只创建并删除测试条目）
EASYAGENT_NATIVE_KEYCHAIN_TEST=1 go test -run TestNativeSystemKeychainRoundTrip
EASYAGENT_PREVIEW_SNAPSHOTS=build.noindex/review go test -run 'TestNativeLiveSettingsLayouts|TestPreviewSnapshots|TestSettingsSnapshots'
```

集成测试启动真实核心进程，使用临时数据目录、临时工作区和本机模拟模型接口，覆盖会话/流式输出、真实工具审批、取消、文件、附件、模型保存和重启、会话恢复、终端和关键隔离边界，不请求真实模型。

原生 GUI 验收结束后先退出应用，再撤销测试注册：

```sh
python3 ../scripts/unregister-desktop-apps.py "build.noindex/darwin-arm64/EasyAgent Native Preview.app"
```
